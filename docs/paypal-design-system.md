# One More Thing visual system

Brand colors used in product UI (not PayPal checkout chrome):

| Token | Hex | Role |
|---|---|---|
| Dark blue | `#002B8A` | Primary brand actions, links |
| Light blue | `#029BE1` | Accents, outline buttons, preview |
| Yellow | `#FED13C` | Needs attention |
| Very light blue | `#EBEFF5` | Project cards, soft fills |
| Warm neutral | `#F7F6F3` | App background |
| White / Black | `#FFFFFF` / `#000000` | Surfaces and high-contrast CTAs |

Typography: Outfit (headings) + DM Sans (body/UI). Pill buttons, ~16–20px card radius, ~1200–1280px content width.

Official PayPal branding stays inside the PayPal Buttons / sandbox payment integration only.
