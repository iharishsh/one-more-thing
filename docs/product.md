# Product

**One More Thing** helps freelancers turn vague client “one more thing” requests into reviewed, priced proposals with PayPal sandbox checkout.

## Core loop

1. Capture original agreement + deliverables
2. Paste client request → AI/manual analysis with quotes
3. Freelancer decides classification and price
4. Publish immutable proposal terms + client link
5. Client accepts / declines / requests changes
6. PayPal capture → agreement append + checklist + lock

## Non-goals

- AI never sets the payable price
- Product estimates (Channel3) are not retailer orders
- Demo auth is not a production multi-tenant SaaS without `AUTH_MODE=supabase`
